## Projects

### [ChainGuard](https://github.com/mathieurecatala/chainguard-showcase)
AI-powered security scanner for Solidity smart contracts: seven-agent pipeline (TypeScript / Next.js, Claude API) with retrieval over a curated database of documented DeFi exploits, risk score, prioritized vulnerabilities with suggested fixes, and proof of analysis published on Base.

**Live:** [chainguard-theta.vercel.app](https://chainguard-theta.vercel.app) · source code is private; the linked repo documents the architecture and design decisions.

### [mcp-jira-qa](https://github.com/mathieurecatala/mcp-jira-qa)
MCP server for Claude that turns a Jira export into Gherkin acceptance tests. Claude writes the scenarios; the server flags tickets that are not ready to test and only saves scenarios that pass the official Cucumber parser and traceability checks. Demo on fictional data.

### ATS triage pipeline (private)
Python pipeline over public ATS APIs (Greenhouse, Lever, Ashby) that filtered 27,728 job postings down to 11, with a written reason for every rejection.

### [PokemonBlockchain](https://github.com/mathieurecatala/PokemonBlockchain)
On-chain collectible card game: ERC-1155 NFTs (OpenZeppelin, UUPS upgradeable proxy), IPFS metadata, booster packs, React front end with wagmi/viem on Sepolia testnet.
